# 毎日おはV

立ち絵を入れて位置と大きさを合わせるだけで、その日のテーマの「おはようVtuber」画像を出力するツール。
GitHub Pages でそのまま公開できる静的サイト（フレームワーク・ビルド不要）。

## 公開ルール（今日から7日分）

- 画面上部の日付タブに「今日〜6日後」の7日分が並び、その中から選べる
- テーマが置かれていない日は「準備中」でタブが押せない
- 前日以前のテーマは表示されない（日付が変わると自動で1日ずつ進む）
- URL の `?date=YYYY-MM-DD` はこの7日の範囲内だけ有効。範囲外は今日に戻る
- 制作確認用：`?dev&date=YYYY-MM-DD` で範囲の制限なしに、その日から7日分を並べる

※ GitHub Pages の公開リポジトリでは、ファイルのURLを直接たたけば範囲外のテーマも読めてしまう。
　画面上の制限として運用し、先の分を完全に隠したい場合は「公開用ブランチに7日分だけ置く」
　GitHub Actions を追加する（必要になったら対応）。

## ディレクトリ構成

```
index.html                 … 画面（固定）
.nojekyll                  … GitHub Pages に Jekyll を通させない
core/                      … 基幹（固定。テーマを増やしても触らない）
  engine.js                … 描画エンジン：擬似3Dステージ / アクスタ / 日付カレンダー / 小物キット / 文字
  app.js                   … 7日分のテーマ読込・日付タブ・立ち絵の保存・スライダー・保存/X投稿
  style.css
THEME_GUIDE.md             … テーマ制作ガイド（ルール・手順・確認方法）★テーマを足すときはここから
tools/check/render.py      … 描画確認（制作用。ヘッドレスブラウザで出力PNGと拡大図を作る）
assets/themes/             … テーマ置き場（ここに足し続ける）
  _template/theme.js       … 新テーマのひな形
  2026-09-26/              … フォルダ名＝その日の日付（YYYY-MM-DD）。1日1フォルダ
    theme.js
    （画像を使う場合は同じフォルダに置き、theme.js の assets に書く）
  2026-09-27/
  …
```

一覧ファイルはない。アプリが7日分の日付フォルダの `theme.js` を直接読みに行く。
キャッシュ対策として、読み込みURLに当日の日付が付く（日付が変われば必ず取り直す）。

## テーマの足し方

**→ `THEME_GUIDE.md` を読む。** ルール（構図・日付・作り込みの水準・置かない小物・ライティング・失敗時の扱い）、
手順、部品の早見表、仕上げチェックリストはすべてそこにまとめてある。

1. `assets/themes/_template` をコピーしてフォルダ名をその日の日付（例 `2026-10-02`）にする
2. `theme.js` の `id`・`title`・`dayName` と `render()` を書く
3. `python3 tools/check/render.py 2026-10-02 --zoom` で描画と拡大図を確認する
4. コミットして GitHub Pages に反映すれば、その日の7日前からタブに出てくる

保存される画像のファイル名は `ohav-日付-id.png`（例：`ohav-2026-09-26-bath-day.png`）。

## 共通キャプション（基幹側で自動）

全テーマ共通で、上部に大きく「Good Morning」、下部に英語の「◯◯の日」を Righteous で重ねる
（`core/engine.js` の `drawDayCaption`、`core/app.js` がテーマ描画の後に呼ぶ）。
テーマ側で書くのは下部の文言だけ。
上下とも横幅いっぱいまで広げる（下の上限は「Good Morning」と同じ大きさ）。
下の文言が長く1行だと小さくなりすぎる場合は、単語の切れ目で自動的に2行に組む。

```js
dayName: 'Coffee Day',                              // 下部の文言
caption: { fill: '#fffaf2', outline: '#4a2c17' },   // 色（任意）
// caption: false                                   // 出さないテーマだけ
```

## アクリルスタンド（基幹側の部品）

`E.acrylicStand(env)` で立ち絵からアクスタ一式（カット・縁・ツヤ・台座）を作れる。
寸法は全テーマ共通（板 1.1×1.5、立ち絵の既定枠 0.74×1.0）なので、スライダーの効き方も揃う。
置き場所と向きは `{ x, z, yaw }` で指定（yaw で斜めに振る）。使い方は `_template/theme.js` を参照。
表面の反射（縁の光・斜めのツヤ・上端の映り込み）は白を重ねるだけで、どの画素も最大約45%に抑えて白飛びを防いでいる。

## ローカルで確認するとき

`index.html` を直接開いても動くが、テーマに画像ファイルを使う場合は
ブラウザの制限で保存できなくなるため、簡易サーバーで開く。

```
python3 -m http.server 8000
# → http://localhost:8000/
```

## 利用者側の動き

- 初回：立ち絵をえらぶ → 位置・大きさを合わせる → 保存 / Xに投稿
- 2回目以降：立ち絵と位置はブラウザに保存されているので、開くだけで今日の画像が出る
- 日付タブで明日以降の分も先に作っておける（位置の調整は日ごとに保存）
